# Cove 全流程图（总览 + 模块内细化）

说明：本文件在端到端总流程基础上，补充各大模块内部运作流程，便于做技术展示与系统讲解。

## 1) 端到端总流程（保留总览）

```mermaid
flowchart TD
    A[启动 cove 进程] --> B[解析 CLI 参数]
    B --> C{参数分支}

    C -->|--version/--help/--doctor/--config| C1[直接执行并退出]
    C -->|正常启动| D[bootstrapApp 初始化]

    D --> D1[配置加载与迁移]
    D --> D2[构建 Provider/Engine/Registry]
    D --> D3[初始化 Permission/MCP/Skills/Memory/Plugin]
    D --> D4[启动诊断 + Banner]

    D4 --> E{运行模式}
    E -->|--dump-system-prompt| E1[打印系统提示词后退出]
    E -->|-p/--print| F[一次性模式 runPrintMode]
    E -->|默认| G[交互模式 runREPL]

    F --> F1[构造消息和附件]
    F1 --> H[runChatInteractionMessage]
    H --> I[Engine.RunWithStream]
    I --> J[输出结果]

    G --> G1[REPL 行编辑器输入 + 补全]
    G1 --> G2{输入类型}
    G2 -->|斜杠命令| G3[命令注册表执行]
    G2 -->|普通消息| G4[任务入队 TaskRunner]
    G4 --> H
    G3 --> G1

    J --> Y[保存会话与成本 / SessionEnd hook / 默认 Dream 退出门禁]
    G1 -->|/exit 或 EOF| Y
    Y --> Z[进程结束 / 已启动的 Dream worker 继续运行]
```

## 3) REPL 主循环与异步任务队列

```mermaid
flowchart TD
    A[runREPL 启动] --> B[构建命令列表和补全器]
    B --> C[创建 replTaskRunner]
    C --> D[读取输入]

    D --> E{终端事件}
    E -->|Ctrl+C 且任务运行中| E1[CancelRunning]
    E -->|/exit| E2[SaveSession + 退出]
    E -->|普通输入| F{是否权限提示输入通道}

    F -->|是| F1[转发到 PermissionPrompt]
    F -->|否| G{输入类型}

    G -->|/xxx 命令| H[命令执行]
    G -->|continue/继续| I[重试失败任务或恢复草稿]
    G -->|普通消息| J[Enqueue 到任务队列]

    J --> K{可合并排队任务?}
    K -->|是| K1[合并补充要求]
    K -->|否| K2[追加队列]

    K1 --> L[startNextLocked]
    K2 --> L
    L --> M[后台 goroutine run]
    M --> N[runChatInteractionMessage]
    N --> O{执行结果}
    O -->|成功| O1[清理中断草稿]
    O -->|失败| O2[保存 pendingFailedMsg + interrupted draft]
    O1 --> P[finishLocked + 尝试下一个任务]
    O2 --> P
    P --> D
    H --> D
    I --> D
```

## 5) 引擎回合主流程（Engine.RunMessageWithStream，internal/engine/turn_loop.go）

```mermaid
flowchart TD
    A[接收用户消息] --> B[写入 messages，建检查点基线]
    B --> C[构建 SystemPrompt: tools/skills/memory/context/拆任务引导]
    C --> D["iterationStart：预算与轮次上限检查<br/>token 达 CompactionTrigger 时压缩历史"]
    D --> E[callModel：按路由选模型，流式输出]
    E --> F{响应类型}
    F -->|纯文本| G[finishOrNudge]
    F -->|带 tool calls| H[dispatchTools：并发安全工具并行(上限8)，write/edit 按路径认领，其余串行]
    H --> I[executeTool（见 §6）]
    I --> J[afterIteration：结果回灌、LoopDetector.RecordIteration、断路器与模型升级]
    J --> D

    G --> G1{完成校验门禁 / 自审 / todo 提醒 / 停止提示?}
    G1 -->|需继续| D
    G1 -->|完成| L[saveSession + cost/ratelimit 更新 + 验收证据落盘]
    L --> M[runTurnEndPipeline（见 §12）]
    M --> N[返回最终文本]
```

## 6) 单次工具执行内部流程（executeTool，internal/engine/engine.go）

```mermaid
flowchart TD
    A[按名称查找 Tool] --> B{存在?}
    B -->|否| B1[返回 unknown tool]
    B -->|是| C[BeforeTool hook]
    C --> D[Guardrail.BeforeCall]
    D --> D1{Block?}
    D1 -->|是| D2[返回阻断错误]
    D1 -->|否| E[write/edit：先建自动检查点]
    E --> F[构造 tool.Context]
    F --> G{shell 分类器}
    G -->|灾难命令| G1[硬拦截]
    G -->|通过| H[Validate 输入]
    H --> I[authorizeToolCall：Tool.CheckPermissions → plan 门禁 → permission.Manager.Check（见 §7）]
    I --> J{allow/ask/deny/bypass}
    J -->|deny| J1[返回拒绝]
    J -->|ask| J2["授权提示 [y] 允许 [a] 本会话记住 [p] 本项目记住 [n] 拒绝 [e] 拒绝并说明"]
    J2 -->|拒绝| J3[返回拒绝（带理由时回传 user rejected: 理由）]
    J2 -->|允许| K[t.Call]
    J -->|allow/bypass| K
    K --> N{执行错误?}
    N -->|瞬时错误| N1[重试一次]
    N -->|仍失败| N2[Guardrail.AfterCall(error) + 返回错误]
    N -->|否| O[Guardrail.AfterCall(success)]
    N1 --> O
    O --> P[AfterTool hook + trackFileChanges + 输出裁剪 + LoopDetector.RecordOutput + 条件技能注入 + 子目录提示]
    P --> Q[返回结果给模型]
```

## 7) 权限系统内部决策流程（permission.Manager.Check，internal/permission/permission.go）

```mermaid
flowchart TD
    A[输入: toolName + toolInput + defaultDecision] --> B[匹配 deny 规则（含 policies.json 的规则，按归一化命令匹配）]
    B --> C{命中?}
    C -->|是| C1[DDeny: denied by policy rule]
    C -->|否| D{mode == plan?}
    D -->|是| D1[只放行只读工具、整行只读命令、PlanSafe 工具；其余 deny]
    D -->|否| E{mode == bypass?}
    E -->|是| E1[DBypass]
    E -->|否| F[按 priority 匹配 ask / allow 规则（同级 ask 优先）]
    F --> G{命中?}
    G -->|ask| G1[DAsk]
    G -->|allow| G2[DAllow]
    G -->|否| I{mode}
    I -->|auto| I1[只读工具/只读命令/构建测试命令/项目内 write、edit allow; 其余 ask]
    I -->|default| I3[只读工具/整行只读命令 allow; 其余 ask]
```

## 8) 计划执行器内部流程（execute_plan / plan executor）

```mermaid
flowchart TD
    A[todowrite 产生任务清单] --> B[execute_plan 调用 PlanExecuteFunc]
    B --> C[FromRuntime 构建 Plan]
    C --> D[topologicalSort 依赖层级]
    D --> E{存在环?}
    E -->|是| E1[所有任务 failed: circular dependency]
    E -->|否| F[逐层执行]

    F --> G{parallel 且同层>1?}
    G -->|是| G1[并发执行, sem 限制 MaxParallelAgents=4]
    G -->|否| G2[串行执行]

    G1 --> H[runTask]
    G2 --> H

    H --> H1[读取依赖输出 + 注入消息]
    H1 --> H2[delegator.Delegate 调子智能体]
    H2 --> H3{成功?}
    H3 -->|否| H4[按 maxRetries 重试 默认1]
    H3 -->|是| H5[标记 done + 回写 runtime]
    H4 --> H6{重试后仍失败?}
    H6 -->|是| H7[标记 failed]
    H6 -->|否| H5

    H5 --> I[更新 completed]
    H7 --> I
    I --> J{有依赖失败?}
    J -->|是| J1[下游 pending 标记 skipped]
    J -->|否| K
    J1 --> K[进入下一层]
    K --> L[汇总 ExecutionResult]
```

## 11) 三层循环检测流程 (LoopDetector，internal/engine/loopdetect.go)

```mermaid
flowchart TD
    A[RecordToolCalls(fingerprint) / RecordOutput(output) / RecordIteration()] --> B{只读工具?}
    B -->|是 read/grep/glob 等| C[跳过检测]
    B -->|否| D[Layer1a: 精确指纹匹配]

    D --> E[sha256(toolName+input) 入 14 轮窗口]
    E --> F{相同指纹 ≥10 次?}
    F -->|是| G[Warning]
    F -->|否| H[Layer1b: 工具名匹配（toolOnlyWindow）]

    H --> I[工具名入 12 轮窗口]
    I --> J{相同工具名 ≥10 次?}
    J -->|是| G
    J -->|否| K[Layer2: 输出哈希匹配]

    K --> L[sha256(output 前 512 字节) 入 40 轮窗口]
    L --> M{相同哈希 ≥8 次?}
    M -->|是| G
    M -->|否| N[Layer3: 停滞检测（stallThresh）]

    N --> O{连续 60 轮无文件读写?}
    O -->|是| G
    O -->|否| P[返回 None]

    G --> Q{breakCount < 上限?}
    Q -->|是| R[注入引导 + 清空窗口 + 返回 Warning]
    Q -->|否| S[返回 Fatal 硬终止]
```

另：模型故障回退不是跨 provider 的 ModelFallback（`api.ModelFallback` 没有调用方），而是 `fallbackModel()` 在 `model` 与 `model_fast` 之间切换：快速模型连续失败时本轮改用高级模型。

## 12) 回合后自学习流水线（runTurnEndPipeline）

```mermaid
flowchart LR
    A[runTurnEndPipeline] --> B[SessionNotes.Flush 同步]
    A --> C[runBackgroundWork 单个受跟踪的后台任务]
    C --> P[按 max_sessions 清理旧会话]
    P --> L{允许学习且预算未耗尽?}
    L -->|是| F[ExtractWithSource / 30 秒超时 / 沉淀长期记忆]
    F --> E{Dream trigger?}
    E -->|threshold| H[检查阈值与整理锁 / 可启动后台整理]
    E -->|默认 session_end| S[回合后不启动 Dream]
    H --> D[有待评审消息时执行技能评审]
    S --> D
    L -->|否| R[汇报保存与清理结果]
    D --> R
```

`--no-auto` 或本地 provider 会关闭回合后的自动学习，但不关闭会话保存、笔记和旧会话清理。默认 `session_end` 模式由 CLI 退出路径在 SessionEnd hook 后检查 Dream 门禁，满足条件时启动独立 worker；`--no-auto` 会跳过。`WaitBackground` 等待提取与清理，不等待技能评审或独立 Dream 整理。
